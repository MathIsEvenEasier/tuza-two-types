Graph class

What are the two types?

A split graph has a clique K, where every pair of vertices is joined, and an independent set I, with no edges between its vertices. Each vertex in I has neighbors in K.

We allow at most two distinct neighborhoods of size at least two, called S and T. Their sizes, overlap, and numbers of copies are arbitrary. Outside vertices of degree zero or one belong to no triangle and do not affect either optimum.

Why the cover works, and what the browser computes

Split the clique into A and B. Select every clique edge inside A or inside B. For each outside vertex, also select the spokes to the smaller of its two neighbor groups. A clique triangle has two vertices on the same side. A triangle using an outside vertex either has an already selected core edge, or crosses the cut and meets a selected spoke.

The browser chooses the least costly of the 64 cuts of this six-vertex clique. For the packing it tries a fixed, bounded collection of greedy orders and sum-color classes, keeping the largest edge-disjoint family it finds. It checks every displayed triangle and every cover incidence directly. The displayed packing gives a lower bound on ν△, and the cover gives an upper bound on τ△. Their sizes can differ from the optima. The example is limited to six clique vertices; the Lean theorem applies to every clique size.

C(A) = (|A| choose 2) + (|B| choose 2) + p min(|S ∩ A|, |S ∩ B|) + q min(|T ∩ A|, |T ∩ B|)

03 / Why multiplicities can be capped

From matching colors to triangles

One neighborhood S. Assign each matching color to a different outside vertex. Edges of the same color never touch, so triangles at that center never reuse a spoke.

For compression, start with any packing, collect its used edges inside S, and recolor them. Assign their triangles to at most h(s) centers. Triangles outside this neighborhood group stay untouched, so the packing has the same size.

Why the cover number also stops changing

With s−1 twins, let J be the neighborhood edges not already selected in a cover. Each twin’s selected spokes meet every edge of J. The cheapest such spoke set Z gives |J| ≤ (s−1)|Z|, no more than the total number of selected spokes at all twins. Replace those spokes by J. This cover works for any number of extra twins at no greater cost.

Applying the packing and cover arguments gives a common cap h(s) that preserves both optima. The arguments allow the other neighborhood type to be present.

04 / A second way to pack triangles

Triangle sums give disjoint edge sets

Label the n vertices by distinct residues modulo n. Color each triangle by the sum of its three labels. Every color class is an edge-disjoint packing.

a + b + c = a + b + d (mod n)
↓ cancel the shared edge
c = d (mod n)

Two triangles of the same color sharing the edge ab must also have the same third vertex. They are the same triangle.

So each color class is a packing. The largest of n classes has at least 1/n of all triangles. This supplies a uniform packing bound for an arbitrary graph, including the clique core.

05 / The two certificate domains

Covering all clique sizes

Compression makes each fixed k finite. Normalization handles all large k together. Both reductions are proved in Lean.

After separate lemmas handle some parameter ranges, divide neighborhood sizes, overlap and capped multiplicities by k:

(x, y, w, α, β, ρ)
= (s/k, t/k, u/k, p/k, q/k, 1/k)

The remaining graphs map into a constrained six-dimensional real domain. A finite tree divides that domain into boxes. Every leaf has a checked inequality or is proved infeasible. The joins prove that no part of the domain is missed.

All arithmetic bounds use exact directed rounding, and the soundness proofs connect them to real inequalities. No floating-point evaluation is trusted.

01/43

Every integer k ≥ 43 gives a point in this interval. The endpoint ρ = 0 is included to make the domain closed; it is not the value of 1/k for any finite graph.

The finite certificate covers 2 ≤ k ≤ 42, and the interval certificate covers k ≥ 43. For k < 2 there are no triangles.

Where this fits

Packing triangles and removing them

Each triangle in an edge-disjoint packing forces us to remove a different edge if we want to eliminate all triangles. Thus ν△ ≤ τ△ for any graph. For the graphs studied here, the theorem also gives τ△ ≤ 2ν△.

For example, if a largest packing has 10 triangles, between 10 and 20 edge deletions are needed. Multiplicity compression reduces a graph with a clique of size k to at most 3k vertices while preserving both optima. Computing those optima remains a separate algorithmic problem.

Related work

Zijian Zeng’s 2026 preprint treats a specified eight-vertex clique part with two types. Here, the clique size is unrestricted.
